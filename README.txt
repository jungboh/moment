MOMENT 홈페이지 배포 파일

구성 파일
- index.html: 첫 화면
- events.html: Moment 이야기
- packages.html: 서비스
- portfolio.html: 포트폴리오
- booking.html: 예약/문의
- concept.png: 공통 이미지 리소스

AWS 서버 업로드 방법 예시
1. EC2 서버에 접속합니다.
2. 웹 루트 폴더로 이동합니다. 예: /var/www/html
3. 이 폴더 안의 파일들을 모두 업로드합니다.
4. 브라우저에서 서버 주소 또는 도메인으로 접속합니다.

주의
- index.html이 루트에 있어야 첫 화면이 바로 열립니다.
- 파일명은 영문/숫자 중심으로 유지했습니다.
- 별도 빌드 과정이 없는 정적 HTML 사이트입니다.
